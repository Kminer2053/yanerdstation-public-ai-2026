# 모바일 따라걷기 카메라 PIP와 사람 표시

- 모바일 카메라 비교를 상하 1:1 분할에서 우하단 PIP로 변경. 지도 영역의 가로 40% × 세로 42%(면적 약 1/6)를 차지하며 3D 화면은 분할하지 않는다.
- 조작줄의 실제 높이를 반영해 PIP를 올리므로 세부 조작을 펼쳐도 겹치지 않는다.
- 카메라 원본 영상의 비율은 유지하며 잘라내지 않는다. 닫기와 권한 오류 안내는 유지한다.
- 따라걷기 하단에 사람 표시 켜기/끄기 버튼을 추가. 기존 사람 체크박스와 상태를 공유하고 기존 지도 메시지로 즉시 적용한다.
- 화면 정리 및 카메라 비교 중에도 사람 버튼을 사용할 수 있다. 경로·보행 진행에는 영향이 없다.
- 데스크톱의 기존 좌우 비교, 카메라 권한·종료 처리, 공개 편집기 및 확정 데이터는 변경하지 않는다.

## 검증

- `node tools/test-mobile-pip.mjs`: PIP 크기·레이아웃 계약과 사람 토글 양방향 동기화 통과.
- `npm run test:experience`: API·데이터·경로·카메라 수명주기 회귀 검사 통과.
- `npm run build`, `git diff --check` 통과.
- 기존 로컬 4202 서버와 모의 카메라 fixture를 사용해 390×844 / 360×780에서 확인. 실제 카메라를 켜거나 촬영하지 않음.
- 390px: 지도 전체 폭 390px 유지, PIP 156×246.5px, 조작줄과 겹침 없음. 사람 표시 꺼짐/켜짐 및 체크박스 동기화 확인.
- 360px: 세부 조작 펼침에서도 PIP 하단 493.5px < 조작줄 상단 502px, 가로 넘침 없음.
