# 플랫폼111 2프레임 · 2층 자연채광 로컬 시안

상태: 코드·자동검사·빌드 및 실제 화면 검증 완료. 운영 사이트 미배포. 초기 브라우저 접근 오류는 사용자가 페이지를 정상 로드한 뒤 해소되었으며 동일 내장 브라우저로 검증을 재개했다. 최종 렌더링 측정 결과는 별도 측정 산출물에 기록한다.

## 변경

- 플랫폼111 광고는 기존 시연 영상의 정지 이미지와 `PLATFORM 111` 문구를 각각 4초씩 교대.
- 영상 디코더와 프레임별 동영상 텍스처 업로드 대신, 미리 읽은 이미지 두 장 중 표시할 번호만 변경.
- 2층·3층 표현은 하나의 타이머를 공유. 화면 밖·숨긴 탭·모션 감소 설정에서는 자동 전환 중지.
- 광고 이미지 전용 텍스처를 사용해, 늦게 도착한 기존 카탈로그 이미지 요청이 새 광고 이미지를 덮어쓰지 않도록 분리. 실제 화면에서 재현된 상하 흰 여백이 사라지고 새 이미지가 전광판 높이 전체를 채우는 것을 확인.
- 열차안내 영역의 사진·투영 및 시설 형상·서울역 저장 잠금·등록 데이터는 유지.
- 2층에서 3층 바닥이 덮는 구역은 사각 LED 실내조명 유지.
- 상부층으로 덮이지 않은 2층 바닥은 시간대 자연채광과 하늘 표현 적용.
- 2층 선상통로는 야외 테라스로 분류. 세부 바닥 자료가 없는 곳도 기존 선상통로 근사 경계의 2층 높이(33–42m 미만)에서는 야외 분류. 정확한 상부 바닥 피복 판정이 있으면 이를 우선하며, 지하·3층 이상 분류는 유지.
- 조도와 태양 표현은 시각화용 근사치이며 실제 측정 조도나 그림자 시뮬레이션이 아님.

## 검증

- `node tools/test-platform111-slides.mjs`: 공유 타이머, 교대, 숨김/모션 감소/정리, 텍스트 방향, 구역 구분 검사 통과.
- `node tools/test-lighting-platform111.mjs`: 조명 구역, 천장, 화면 형상·열차안내 보존 검사 통과.
- `node tools/test-feedback.mjs`: 기존 피드백 회귀 검사 통과.
- `npm run test:experience`: 권한·저장 충돌·데이터 합계·552개 경로·카메라 생명주기 회귀 검사 통과.
- `npm run build`: 통과. 기존 대형 번들 경고 있음.
- 로컬 `/app/`와 새 문구 SVG: HTTP 200.

## 실화면 검증

1. 로컬 4202의 개방 맞이방: 낮 12시 `daylight`, 하늘 켜짐, 광원 1.40 확인.
2. 선상통로: 야외 판정, 낮 1.40 → 밤 0.50 광원 전환과 하늘 변화 확인.
3. LED 피복 구역: 밤에도 `led`, 하늘 꺼짐, 고정 광원 1.55 유지 확인. 조명 구역 판정 검증이며 전체 천장 마감 품질 승인과는 구분한다.
4. 플랫폼111 이미지/문구 각각 확인. 이미지 상하 흰 여백 없음, 문구 정방향, 열차안내 사진 유지. 4초 공유 타이머는 단위검사와 정상 화면 교대로 확인.
5. `/_perf/`는 임시 로컬 진단 화면이며 Git에서 제외. 기존 영상 / 두 프레임 / 고정 화면을 동일 조명·지도·카메라·시간대로 비교한다. 사용자의 일반 PC 실측과 혼동하지 않으며, 사람 ON의 적응형 인원수 차이도 함께 기록한다.

측정과 화면 캡처: 상위 작업폴더의 `outputs/platform111_two_frames_20260929/`. 영상의 GPU 업로드 횟수와 프레임 속도를 분리해 기록한다.
