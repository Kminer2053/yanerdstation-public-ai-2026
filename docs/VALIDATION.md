## 임시 실행과 읽기 확인

사용자가 4196·4197 포트의 제출본 임시 실행을 허용했다. 두 서버는 `127.0.0.1`에만 연결하고 기존 프로세스를 변경하지 않았다. 다음 읽기 응답이 정상임을 확인했다.

- 서비스 `/api/catalog`: 337 기준 시설·경로 스냅샷.
- 서비스 `/api/demo/sales?date=2026-07-18`: 독립 합성 자료임을 `basis`에 명시한 매출 JSON.
- Toolkit `/api/public/stations`: 공개 역 목록.

### 실제 브라우저 확인

공개 제출본의 `/seoul/?role=visitor`를 처음 연 브라우저에서 약 40초 관찰 후 **‘3D 지도 연결됨’** 상태와 실제 VWorld 실내 3D 화면을 확인했다. CesiumJS와 VWorld 메타데이터는 HTTP 200이었고 해당 관찰의 `pageerror`는 0건이었다. 처음 22초 관찰에서는 아직 연결 중이었으므로 이를 지도 실패로 판정하지 않는다. 약 40초는 한 차례 관찰 시점이며 일반적인 로딩 성능을 보증하는 수치가 아니다.

공개본 UI에서 시설 115건 목록과 검색 동작도 확인했다. 가상 보행자의 사람 600·점 4,808 표시는 합성·모형 결과이며 실제 현장 인원 측정이 아니다. 이 확인은 모든 시설의 화면 위치·모든 경로·모든 기기/브라우저를 전수 검증한 결과가 아니다.

실제 클릭 장면과 구동영상은 별도 제출 증거(`submission evidence`)로 관리한다. 외부 공간의 첫 로딩과 대기 시간을 실제 구동과 구분해 제시하며 원본 지도 캐시를 저장소에 추가하지 않는다.

## 공개본 최종 파일 검사

node_modules·dist·data-private·Git 이력을 제외한 공개 소스에서 원본 영상/3D 타일 바이너리(`mp4`, `webm`, `mov`, `b3dm`, `pnts`, `bin`), 운영 hosting 파일, 사용자 로컬 절대경로와 개인 이메일을 발견하지 않았다. 일반적인 고신뢰 API키·토큰·private key 서명 검사도 검출 0건이다.

사진 대체 대상은 96개이며 원사진 없이 절차 생성한 표지로 모두 덮어썼다. 매출·이용인원은 원값을 입력으로 쓰지 않는 생성기로 다시 작성했다. 개인정보 신청서와 서명 문서는 공개 소스에 포함하지 않는다. 이 검사는 알려진 패턴과 구성 범위를 확인한 것으로 모든 권리와 개인정보 검토를 보증하는 인증은 아니다.

## 남는 한계

실제 유료 모델 호출·운영 정확도·응답 비용은 이번 검사에서 측정하지 않았다. 테스트의 모델 응답은 모의값이다. Ebi 자동 호출 연결도 별도다. 원사진·실제 영업자료·원본 VWorld 자산은 배포하지 않아 공개 clone은 합성 표지와 샘플 수치로 표시한다. 외부 공간 서비스와 재이용·시연 조건은 별도 확인해야 한다.

루트 지도 번들은 minify 후 약 545kB로 Vite의 500kB 안내가 있었다. 빌드는 성공했으며 번들 크기 개선은 잔여 품질 과제다.

## 공개 범위 때문에 제외되는 옛 선택 검사

`node tools/test-lighting-platform111.mjs`는 이전 홍보영상 파일의 존재와 10KB 초과 크기를 함께 요구한다. 이 공개본은 해당 영상 원본을 의도적으로 제외해 그 자산 전제에서 실패한다. 해당 검사를 숨기거나 약화시키지 않았으며 기본 `npm test`의 필수 검사와 구분한다. 조명 상태 캐시 변수 정리 자체는 구문 검사·빌드와 최종 실제 화면 확인으로 별도 검증한다. 원본 자산이 필요한 보관 도구 전체가 공개 clone에서 통과한다고 주장하지 않는다.

기본 `npm test`는 서버 없이 실행되는 experience·manager·operations 검사 세 가지다. 이전 Chrome/실행 서버 기반 통합 검사는 `npm run test:legacy-browser`에 보존했다. 보안 패치 버전과 공식 근거·회귀 결과는 `SECURITY_UPDATES.md`를 참고한다.
