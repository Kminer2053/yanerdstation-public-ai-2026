# 자유탐색 동시 입력 보완

## 변경

- 화면 버튼을 pointerId별로 추적하여 전진+회전, 전진+점프를 함께 입력할 수 있게 한다.
- 기존 엔진은 이동과 회전을 동시에 계산했으나 UI는 손가락별 상태가 없었고 점프는 손을 뗀 뒤의 click에 의존했다. 점프를 pointerdown으로 옮겨 보조 손가락을 누르는 즉시 실행한다.
- 같은 버튼을 두 손가락으로 누르거나 한 손가락만 해제·취소할 때 나머지 입력을 유지한다. 점프 뒤 발생하는 click은 중복 실행하지 않는다.
- 터치 버튼 상태를 키보드 상태와 분리하여 iframe의 키보드 포커스 변경으로 터치 이동이 중단되지 않게 한다.
- 모드 변경, 페이지 숨김, 창 포커스 상실 때 입력을 초기화한다. 눌린 버튼은 테두리로 표시하고 길게 누를 때의 텍스트 선택·확대를 억제한다.
- 점프는 기존처럼 자유탐색 3인칭 전용. 키보드 Space 및 버튼의 키보드/보조기술 활성화를 유지한다. 보행 가능 구역·충돌 제한은 변경하지 않는다.
- 카메라 PIP, 사람 표시 토글, 편집기, 확정 데이터는 변경하지 않는다.

- `node tools/test-exploration-input.mjs`: 전진+회전+점프, 보조 손가락, 독립 해제/취소, 같은 키 다중 입력, 포커스·모드 초기화, 키보드 접근성 통과.
- `node tools/test-exploration-play.mjs`, `node tools/test-mobile-pip.mjs`, `npm run test:experience`, `npm run build`, `git diff --check` 통과.
- 기존 로컬 4202 서버의 실제 서울역 3D 화면에서 3인칭 진입 및 점프 버튼 키보드 활성화 확인(아바타 ‘점프 중’ 상태).
- 390×844 모바일 화면에서 이동 버튼 44×44px, 점프 버튼 72×46px 및 모든 해당 버튼의 `touch-action: none` 확인.
- 두 손가락 이벤트 시퀀스는 자동 테스트로 검증. 실제 휴대폰 멀티터치 실기기 시험은 수행하지 않음.
