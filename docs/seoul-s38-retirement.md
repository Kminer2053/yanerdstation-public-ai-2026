# F02WL072-S38 FLOWER 부스 숨김

2026-09-14 사용자 내장브라우저의 선택 위치와 원시 타일을 대조한 철거 처리다.

- 대상: 꽃매장 부스의 앞·뒤·옆·상하부 및 부착된 FLOWER 간판 전체.
- 연결 슬롯: F02WL072-S38, S40, S41, S44, S45.
- 2개 LOD 각각 쉘 28삼각형 + 간판 12삼각형. 원시 face 476–515.
- 원본 모델 F02WL072와 TD_ID는 다른 여러 매장이 공유하므로 전체 모델을 숨기지 않는다.
- ENU 영역은 E 28.288–34.821, N 61.261–65.785, U 9.041–12.043m.
- 계단이 위 영역과 겹치므로 공간 박스만으로 지우지 않고 원시 삼각형 위치와 UV를 함께 검사한다.
- 뒤 계단·바닥·별도 승강장 안내표지 F02FC088/F02FC062·후방 광고판 F02FC085는 보존한다.
- 원본 타일, 카탈로그 슬롯, 교체·승인 이력은 삭제하거나 변경하지 않는다. 대상 슬롯의 별도 승인 오버레이도 숨김 상태를 따른다.

## 복원

`app/seoul-s38-retirement.json`의 `enabled`를 `false`로 바꿔 배포하면 원본 부스와 기존 승인 오버레이가 다시 표시된다.
