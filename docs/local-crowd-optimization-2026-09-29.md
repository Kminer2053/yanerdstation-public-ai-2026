# 군중 가시성·거리별 갱신 최적화 — 로컬 검증

## 범위

- 사용자 승인 ① 화면 밖 갱신 축소, ② 거리별 군중 표현 최적화만 적용.
- 기존 로컬 플랫폼111 2프레임/자연채광 시안 위에 적용. 운영 사이트·GitHub에는 배포하지 않음.
- 해상도, 인원 산정식, 경로/층간접속 데이터, 3층 순환 배분, 사람 모델 파일 및 근거리 외형은 변경하지 않음.
- 기존 자동 모델/모의인원 예산 정책은 유지. 성능 비교에서만 자동 예산 변경을 끄고 전후 부하를 고정.

## 구현

- 매 렌더 프레임 전체 인원 검사 대신 다음 이동 시각의 인덱스형 최소 힙 사용. 보이지 않는 사람은 기한을 분산하되 원래 이동 시각 기준으로 따라잡아 이동속도·층간 경로를 보존.
- 카메라 시야 밖 점은 표시 및 좌표 업로드를 멈춤. 화면에 다시 들어오면 위치를 먼저 복원. 회전·이동 중 가시성 검사를 앞당겨 가장자리 누락을 줄임.
- 표시 중인 점만 순회. 가까운 점 20Hz, 중거리 10Hz, 먼 점 4Hz로 좌표 갱신.
- 18m 이내 사람 관절은 매 프레임, 18~45m는 최대 12Hz, 45~90m는 최대 6Hz, 그 이상은 기존 정지 포즈. 몸체 이동은 매 프레임 보간 유지.
- `animationTime`의 동일 값을 재사용해 엔진의 관절 재계산 생략 경로를 이용. 확인 근거: [Cesium 1.142 ModelAnimationCollection](https://github.com/CesiumGS/cesium/blob/1.142/packages/engine/Source/Scene/Model/ModelAnimationCollection.js#L445).
- 사람 표시를 끈 시간은 일시정지 처리. 다시 켤 때 오랜 시간의 이동 계산이 한 프레임에 몰리지 않게 기한을 이동시킴.

## 최종 비교 조건

- Apple M5 / ANGLE Metal / Codex 내장 Chromium 154 / 로컬 캐시 지도.
- 800×520, 2026-07-18 12시. 2F 동일 위치, 동일 초기 인원/난수 배치.
- 전 층 모의 인원 8,082명, 가까운 3D 모델 40명 고정. 3F 배분 약 345명 유지.
- 초기 군중 시각은 준비 중 0으로 고정하고 모델 40개가 준비된 뒤 4초 대기. 측정 때 시각을 진행.
- 같은 실제 경과시간 기준으로 카메라를 좌우 회전(12초). 키 반복이나 각 버전의 FPS에 따라 회전 경로가 바뀌지 않도록 통제.
- 실행 순서: 전 → 후 → 후 → 전 → 전 → 후. 버전별 3회. 측정 중 빌드나 서버 재시작 없음.

## 해석과 한계

- 군중 갱신 시간은 약 49.7% 감소. 하지만 전체 FPS는 -0.7%로 사실상 비슷하며 **FPS 개선은 확인되지 않음**. 프레임 p95도 개선되지 않음.
- 군중 계산 절감과 전체 렌더링 개선은 다른 결과. 이번 근접 시점은 40명 상당수가 근거리 모델로 남아 있어, 거리에 따른 관절 갱신 축소 효과도 제한적.
- 화면 밖 점의 `show` 수는 약 5,365개에서 632개로 줄었지만, 초기 실제 시야 내 점 632개와 전체 모의 인원 8,082명은 동일. 삭제나 인원 축소로 얻은 결과가 아님.
- 렌더 CPU는 scene.preRender→postRender 범위, 군중 시간은 crowd.tick의 별도 범위. GPU는 disjoint timer query. 각 수치를 단순 합산해 전체 프레임 시간으로 해석하지 않음.
- 앞선 짧은 탐색 측정에서는 약 6% 증가가 나왔으나 최종 재측정에서 재현되지 않았으므로 개선율로 채택하지 않음.
- 과거 12.6 FPS는 자동 예산·초기 이동 상태·카메라 궤적이 달라 이번 41 FPS와 직접 비교할 수 없음. 이번 변경으로 12→41 FPS가 된 것이 아님.
- 배포 사이트의 일반 PC·실물 모바일 측정이 아니다. 전체 체감 개선을 보장하지 않음. 현 단계는 군중 계산 비용을 줄인 결과로 한정.

## 검사

- 1만 인원 기한 큐, 2만 회 무작위 재예약, 12/30/60Hz 간 이동·층 전환 일치, 0초 이동 보호 검사 통과.
- 기존 crowd / experience 검사 통과. 보행 가능 격자, 시설 지점, 경로 및 3F 345명 배분 유지.
- 실제 브라우저에서 사람 OFF 후 1시간 경과를 모의하고 ON: 초기 위치와 8,082명 유지, 지연 폭주 없이 복귀.
- 2F→3F 표시 및 오류 로그 확인. 추가 2F 복귀 확인 결과는 출력 폴더의 표시전환검증.json 참조.
- 구문 검사, git diff --check, 프로덕션 빌드 통과. 기존 500kB 이상 번들 경고 유지.
