## 2. VWorld가 작품의 중심이라는 증거

1. 중앙 화면이 VWorld `서울역KTX` 사이트 `S202103`의 실제 3D Tiles이다.
2. 타일 메타데이터의 `FLOOR` 값을 직접 읽어 B2·B1·1F·2F·3F를 전환한다.
3. VWorld 모델의 지리 좌표계를 기준으로 합성 혼잡·점포·시설·경보 레이어를 중첩한다.
4. 화면에 공간 출처, 사이트 ID, 원본 서비스 링크, 데이터가 실제인지 합성인지 상시 표시한다.
5. VWorld 연결에 실패할 때에만 별도의 fallback 화면을 사용한다.

이 다섯 항목은 심사자가 “VWorld 화면을 참고한 별도 대시보드”가 아니라 “VWorld 공간정보를 직접 활용한 서비스”로 확인할 수 있게 하는 최소 증거입니다.

## 5. 회사에서 나중에 받으면 좋은 데이터 형식

현재 개발은 합성데이터로 계속할 수 있습니다. 실데이터 교체 시 아래 형식이면 가장 빠릅니다.

| 파일 | 최소키 | 권장 형식 | 비고 |
|---|---|---|---|
| `stores.csv` | 점포ID, 층, 구역ID, 업종, 영업상태 | UTF-8 CSV | 점포명은 공개 가능명 또는 가명 |
| `monthly_sales.csv` | 월, 점포ID, 매출액, 거래건수 | UTF-8 CSV | 개인 거래내역 제외, 월 집계 |
| `hourly_footfall.csv` | 일자, 시간, 구역ID, 유입·유출·점유 | UTF-8 CSV | 1시간 집계, MAC/얼굴 등 식별자 제외 |
| `facilities.csv` | 시설ID, 층, 구역ID, 유형, 상태 | UTF-8 CSV | 정확한 좌표가 있으면 x/y 또는 경위도 포함 |
| `alerts.csv` | 발생시각, 구역ID, 유형, 심각도, 상태 | UTF-8 CSV | 자유서술 개인정보 제거 |
| `company_profile.xlsx` | 연도, 매출, 인원, 주요고객군, 수행실적 | XLSX | 신청서 기업역량·시장성 문단용 |

민감한 회사 원본은 저장소에 넣지 않고, 공개 가능한 집계본만 출품 자료에 사용합니다.

## 6. 출품 전 차단요인

- **정식 인증:** 현재 공개 VWorld 3D Tiles 연결은 기술 검증용이다. 외부 배포 전 API키·도메인과 재이용 조건을 확인해야 한다.
- **좌표 정밀도:** 합성 구역의 상대좌표는 모델 위에 등록되어 있지만 운영기관 도면과 측량한 정밀 좌표는 아니다.
- **성과 실증:** 매출·혼잡 개선 수치는 현재 모의값이다. “예측/합성” 표기를 유지하고 실제 효과로 주장하지 않는다.
- **공개 가능성:** 공고상 공개검증과 수상작 공익 활용이 예정되어 있으므로 회사 기밀과 제3자 권리 데이터는 분리한다.
