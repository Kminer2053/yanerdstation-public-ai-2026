# 플랫폼111 KTX·자연채광·군중 갱신 개선 배포

## 범위

- 서비스 `yanerdstation.kr` 및 `seoul.yanerdstation.kr`만 반영. 공개 편집기 `toolkit.yanerdstation.kr`는 변경하지 않음.
- 사용자 요청에 따라 현재 해상도 유지: KTX 사진 2,167 × 941, 문구 SVG 1,920 × 640.
- 플랫폼111 광고는 KTX 사진/문구를 4초 교대. 기존 동영상 디코딩·반복 업로드 제거, 정방향 반복, 상하 흰 띠 방지, 출처·CC BY-SA 4.0 고지 포함.
- 천장으로 덮이지 않은 2층 및 선상통로는 시간대 자연채광. 3층 아래 LED 구역 유지.
- 화면 밖 군중 점 갱신 제외, 기한 기반 이동 갱신, 거리별 관절 갱신, 사람 표시 끄기/켜기 일시정지·복귀 개선. 인구 데이터와 인원 상한은 변경하지 않음.
- 확정 시설·경로·카탈로그·심사 잠금·권한은 변경하지 않음.
- 로컬 진단 `/_perf/`와 사용자 `.claude/` 설정은 소스 업로드에서 제외. 파일은 로컬에 보존.

## 검증 근거

- `local-platform111-daylight-2026-09-29.md`, `local-platform111-ktx-2026-09-29.md`, `local-crowd-optimization-2026-09-29.md` 참조.
- 마지막 동일 조건 군중 비교는 전체 FPS 개선을 확인하지 못했으며(41.62 → 41.34), 군중 갱신 CPU 시간은 1.75 → 0.88ms로 감소. 이를 전체 성능 향상 수치로 표시하지 않는다.
- 이미지/문구·조명·군중·기존 경로 및 심사 잠금 회귀 검사와 프로덕션 빌드 후 공식 Sites workflow로 배포.
- sites 원격에 수동 push하지 않는다. 저장 버전과 완료된 배포 ID는 별도 배포 결과 기록에 남긴다.
