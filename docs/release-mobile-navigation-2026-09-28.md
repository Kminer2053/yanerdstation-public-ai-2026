# 모바일 길안내 화면 정리

- 범위: 서비스 방문 안내, 화면 폭 650px 이하. 편집기 및 확정 데이터 변경 없음.
- 목적지 선택 / 시설 목록 / 지도 안내를 동적 화면 높이에 맞춘 세 구간으로 분리. 세로 스크롤 스냅과 하단 바로가기 제공.
- 기존 출발·도착·검색 요소를 이동해 사용하며 복제하지 않음. 데스크톱 전환 시 원래 위치로 복귀, 선택값 유지.
- 따라걷기·카메라 비교 시작 시 통계 및 시점 조작을 자동으로 숨김. `안내 표시`로 복원 가능.
- 일시정지·조망 복귀·카메라 끄기는 유지. 진행률·속도는 `세부 조작`으로 펼침.
- 모바일 카메라 비교는 지도/영상 상하 균등 분할. 조작 바를 위한 별도 하단 공간 확보. 카메라 시작 대기·실패 안내는 유지하고 재생 중 긴 설명만 숨김.
- 실제 카메라의 저장·전송·자동 켜기는 추가하지 않음.

## 확인

- 390×844: 목적지 선택 → KTX&일반열차/테라로사 경로 → 지도 안내 → 따라걷기 자동 간소화 확인.
- 360×780: 비교 화면 분할, 세부 조작 펼침/접기, 카메라 끄기, 시설 목록 전환 확인.
- 1280×900: 모바일 전용 레이아웃 해제, 원래 배치 복원 및 출발·도착 선택 유지 확인.
- 카메라 비교 영상은 `tools/fixtures/mobile-camera.html`의 모의 스트림으로 검증. 실제 휴대폰 카메라 하드웨어는 미검증.
- `npm run test:experience`: 카메라 pending/playing/error/closed 상태 및 기존 인증·경로·데이터 회귀 통과.
- `npm run build`: 통과. 기존 500kB 초과 청크 안내만 발생.
- 시험용 HTML은 Vite 배포 입력에 포함하지 않음.
