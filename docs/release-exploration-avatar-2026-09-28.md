# 자유탐색 아바타·놀이 동작

## 적용 범위

- 자유탐색에서 조망 / 1인칭 / 3인칭을 선택한다. 경로 따라걷기는 기존 1인칭을 유지한다.
- 기존 CC0 사람 모델 1개를 재사용하여 뒤따르는 아바타와 걷기 동작을 표시한다.
- 짧은 점프와 손 흔들기·인사·만세·사진 포즈를 제공한다. 사진 포즈는 이동하거나 점프할 때까지 유지한다.
- 점프는 시각 효과이며 보행 좌표·층 높이를 바꾸지 않는다. 기존 보행 가능 격자와 층간연결 규칙을 우회하지 않는다.
- 벽에 가까우면 추적 카메라 거리를 줄인다. 카메라가 몸에 너무 가까워지면 아바타를 숨긴다.
- 이동·회전·시점 변경·층간 이동 시 포즈를 초기화한다.
- 모바일은 왼쪽 이동 패드 / 오른쪽 점프·포즈 버튼을 사용한다.
- PC 단축키: 방향키/WASD 이동, Space 점프, 1~4 포즈, Enter 층간 이동, Esc 조망.
- 공개 편집기와 확정 시설·경로·영업 데이터, 서울역 저장 잠금은 변경하지 않는다.

## 확인

- `node tools/test-exploration-play.mjs`: 모드 제한, 점프 높이/착지/중복, 포즈 유지/해제, 벽 통과 방지, 클릭 이벤트 회귀 검사 통과.
- `npm run test:experience`, `npm run test:crowd`, `npm run test:release-routing-rendering` 통과.
- `npm run build`, `git diff --check` 통과.
- 로컬 3D 화면에서 3인칭 아바타·사진 포즈·점프 표시 확인.
- 1인칭 전환 및 경로 따라걷기에서는 아바타 놀이 버튼 비노출 확인.
- 모바일 390px 세로 화면의 가로 넘침 없음과 좌우 조작부 배치 확인.

## 배포

GitHub 서비스 저장소에 반영 후 기존 Sites 공식 배포 절차를 사용한다. 앞선 모바일 길안내 개선 커밋 `50c64c1`도 포함한다. 이 문서의 검증 결과는 로컬 검증이며, 운영 배포 완료 여부는 Sites 배포 상태로 별도 확인한다.
