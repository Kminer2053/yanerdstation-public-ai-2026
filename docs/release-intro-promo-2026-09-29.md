# 프로젝트 소개 5장 홍보영상

- 기존 자유탐색 짧은 클립 대신 이미 제작한 56초 세로형 홍보영상 완성본을 사용한다.
- 원본: `yanerdstation-promo-9x16.mp4` (1080×1920, H.264/AAC, 56초). 프리뷰가 아닌 완성본.
- 웹용: 720×1280 / 1080×1920 H.264, AAC, faststart. 장면·길이·소리는 유지하고 비트레이트만 최적화한다. 기존 명명 규칙에 맞춰 큰 버전 파일명은 `promo-1280.mp4`이다.
- 5장 내 영상이 35% 이상 보이면 무음으로 자동재생한다. 화면 이탈·다른 탭 전환 시 정지하고 돌아오면 이어서 재생한다.
- 사용자가 일시정지한 상태는 존중한다. 브라우저의 모션 감소 설정 또는 자동재생 제한 시 기본 재생 버튼으로 직접 재생할 수 있다.
- 기본 컨트롤로 소리·일시정지·탐색·전체화면 조작. 원본 9:16 비율 유지, 자르지 않음.
- 다른 장의 시연 클립과 확대 동작, 서울역 서비스·편집기·확정 데이터는 변경하지 않는다.
- 검증: `node tools/test-scroll-video.mjs`, `npm run test:intro`, 데스크톱/모바일 화면 및 실제 재생 상태, Sites 빌드·배포.
