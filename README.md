# 야!너두 스테이션 · 공개 검토본

현장에서 달라진 매장과 시설을 사진으로 제보하고, AI가 정리한 수정안을 사람이 확인해 실내 지도에 반영하는 참여형 디지털트윈입니다. 2026 공공 AI 대전환 챌린지 자유주제1 제출을 위해 정리한 소스입니다.

이 저장소는 운영 계정이나 데이터를 배포하는 도구가 아닙니다. **실제 서비스 코드와 공개용 합성 샘플**을 함께 제공합니다. 사진 96개와 29개 매장의 매출·이용인원 값은 독립 합성 자료로 교체했습니다. 공개 교통자료의 가공·추정 유동, 시설 등록과 보행 그래프는 구분해 보존했습니다. 실시간 측위·실시간 혼잡 관제나 매출 예측의 실증 결과를 뜻하지 않습니다.

공개 검토 주소: https://github.com/Kminer2053/yanerdstation-public-ai-2026

## 먼저 확인할 장면

1. **사진 제보 → 위치·면 확인 → 수정안 → 사람의 최종 승인.** 제보 문장과 사진 속 문구는 증거로만 취급합니다. AI가 승인 권한을 갖지 않습니다.
2. **원본을 보존하는 변경 레이어.** 사진의 원근·밝기를 보정해 등록한 면에 입힙니다. 없는 면이나 복잡한 3D 형상을 자동 복원했다고 주장하지 않습니다.
3. **같은 공간, 세 이용자.** 이용객은 3D 내비, 사업자는 가상 상권 비교, 철도기관은 시설·경로·자료를 확인합니다. 보행 가능 지점과 등록된 층간 연결을 사용합니다.
4. **확장 가능한 편집 스키마.** 46개 역의 VWorld 실내지도 연결 목록이 있습니다. 46개 역 모두를 서울역 수준으로 현행화한 것은 아닙니다.

## 설치와 실행

Node.js 22.13 이상이 필요합니다(`node:sqlite` 지원). 검증 환경은 Node.js 26.13입니다. 모든 패키지는 프로젝트 폴더에만 설치합니다.

```sh
npm ci
npm start
# http://127.0.0.1:4196/
# http://127.0.0.1:4196/seoul/?role=visitor
# http://127.0.0.1:4196/seoul/?role=business
# http://127.0.0.1:4196/seoul/?role=manager
```

두 번째 터미널에서 편집기를 실행합니다. 루트 설치만으로 Toolkit 의존성이 설치되지는 않습니다.

```sh
cd toolkit
npm ci
npm run dev
# http://127.0.0.1:4197/           사진 제보
# http://127.0.0.1:4197/console/   공개 제보함·승인자 검토
# http://127.0.0.1:4197/editor/    변경 레이어 편집
```

포트가 사용 중이면 기존 프로세스를 종료하지 말고 먼저 실행 환경을 확인하세요. 두 서버는 서울역 iframe과 허용 출처 계약 때문에 기본 4196·4197을 사용합니다. 개발 서버는 127.0.0.1에만 바인딩하고 포트가 겹치면 종료합니다. 처음 실행할 때 Toolkit이 임의의 로컬 승인자 계정을 `toolkit/data-private/local-approvers.txt`에 만듭니다. 이 파일과 로컬 DB·업로드는 Git에서 제외됩니다.

실내 3D 공간은 VWorld/Cesium 외부 접속이 필요합니다. 원본 3D Tiles와 비공개 캐시는 이 저장소에 없습니다. 외부 서비스 지연·권리 조건·정식 API키와 도메인 등록을 별도로 확인해야 합니다. 로컬 캐시가 자동 선택되지 않도록 제출본 기본값을 바꿨습니다.

## 기본 설정과 AI 범위

설정 없는 기본 실행에서는 유료 AI를 호출하지 않습니다. 규칙에 따른 제보 정리·수동 보정·검토를 사용합니다. `.env.example`의 Supabase 설정은 옛 카탈로그를 자신의 프로젝트에 연결할 때만 필요하며 기본 공란입니다. 관리자 비밀키를 `VITE_` 변수에 넣으면 안 됩니다.

AI 서버 연동을 시험하려면 Toolkit 실행 환경에 `AI_API_KEY`, `AI_PROVIDER`(`anthropic` 또는 `openai`), `AI_MODEL`을 명시합니다. 자신의 계정에서 사용 가능한 이미지 입력 모델 ID를 사용하고 키를 소스나 브라우저에 넣지 않습니다. API를 연결하면 사진 전송·모델 이용료가 발생할 수 있습니다.

AI API 요청·응답 검증·초안 저장 코드는 구현되어 있습니다. 저장소 테스트는 실제 이미지와 **모의 모델 응답**으로 검증합니다. 실제 운영 모델 왕복·정확도·시간 절감·비용 효과의 실증과는 구분해야 합니다. 대화형 Ebi 자동 호출은 별도 연결이 필요합니다. 설정 없이 완료된 것처럼 표시하지 않습니다.

## 검증

서버나 운영 DB를 시작하지 않는 검사입니다.

```sh
npm run build
npm run test:experience
npm run test:manager
npm run test:operations
cd toolkit
npm test
npm run test:reports
npm run test:ai-work
npm run test:dots-work
node tools/test-chat-work.mjs
npm run build
```

`npm test`(루트)는 별도 Chrome·실행 서버·외부 지도에 의존하는 옛 통합 검사이므로 위 목록의 독립 검사와 구분합니다. 일부 보관 도구는 원자료를 별도 입력으로 요구합니다. 공개 clone만으로 원자료 수집과 과거 Supabase 전체 복원을 재현한다고 주장하지 않습니다. 실제 검사 결과는 [검증 기록](docs/VALIDATION.md)을 확인하세요.

## 소스 구조

| 위치 | 내용 |
|---|---|
| `seoul/`, `src/experience*`, `app/` | 세 이용자 UI·3D 화면·경로·현장 변경 |
| `toolkit/src/`, `toolkit/server/` | 사진 제보·보정·AI 초안·승인·변경 레이어 |
| `server/`, `db/`, `drizzle/` | API·권한·데이터·D1 스키마 |
| `public/data/` | 공개 검토용 스냅샷·보행 그래프·가공/추정 유동·합성 이용인원 |
| `server/data/sales.json` | 실제 자료와 독립적으로 생성한 합성 매출 |
| `tools/`, `toolkit/tools/` | 생성 도구·메모리 DB/API 검사 |

사진 대체 표지는 `node tools/make-public-demo-images.mjs`, 합성 매출·이용인원은 `node tools/make-public-demo-data.mjs`로 다시 생성합니다. 원사진이나 영업 원자료를 읽지 않습니다.
