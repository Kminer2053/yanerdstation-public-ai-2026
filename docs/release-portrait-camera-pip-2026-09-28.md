# 따라걷기 모바일 카메라 PIP — 실제 영상 비율 유지

- 사용자의 추가 지시에 따라 강제 세로형·좌우 잘라내기를 철회했다. 앞선 3506995의 세로형 cover 시안은 GitHub에만 반영했으며 Sites에 배포하지 않았다.
- PIP는 실제 `videoWidth / videoHeight` 비율로 크기를 계산한다. 세로 입력은 세로형, 가로 입력은 가로형으로 표시하며 메타데이터/영상 크기/화면 크기 변경에도 갱신한다.
- 지도 높이의 42%, 너비 40% 및 조작줄을 제외한 가용 공간 이내에서 전체 영상 비율을 보존한다. 영상과 창의 비율을 같게 하여 검정 여백 없이 표시한다.
- 강제 aspectRatio 요청을 제거하고 카메라의 resizeMode는 none을 선호한다. PIP는 contain으로 원본 전체를 보존하며 회전·늘이기·좌우 잘라내기를 하지 않는다.
- 데스크톱 카메라 비교는 기존 contain 표시를 유지한다. 카메라 권한·종료 처리, 사람 표시 토글, 조작줄 회피, 확정 데이터 및 편집기는 변경하지 않는다.

## 검증

- `cameraPipSize` 자동 테스트: 가로·세로·정사각형 원본과 390/360px 및 낮은 화면에서 원본 비율, 공간 제한, 조작줄 회피 확인.
- 실제 3D 로컬 화면에서 모의 1280×720 영상은 390px 화면에서 156×87.75px, 360px 화면에서 144×81px의 가로 PIP로 표시. 영상과 창의 크기·비율이 동일하며 조작줄과 겹치지 않음.
- 재생 중 모바일 제목 바는 숨기고 닫기 버튼만 유지하여 가로 PIP 영상을 덜 가린다.
- 실제 카메라 권한을 요청하거나 촬영하지 않고 모의 영상으로 레이아웃 검증.
- `node tools/test-mobile-pip.mjs`, `npm run test:experience`: 강제 비율 없음, 재생/중단/권한 거절, PIP 스타일 및 사람 토글 회귀 검증.
- 서비스 GitHub main 반영 후 기존 Sites 공식 workflow로 빌드·패키징·배포. 공개 편집기는 변경하지 않는다.
