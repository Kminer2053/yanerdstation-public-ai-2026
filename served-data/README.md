# 운영 데이터 읽기 전용 내보내기

이 폴더는 실제 서비스의 Cloudflare D1 업무 테이블을 Sites 읽기 도구로 조회한 기록이다. 데이터 수치나 업무 내용을 새 합성값으로 바꾸지 않았다. 서울역 서비스의 정적 시설·경로·상권·승인 사진 데이터는 서비스 v77 소스에, 편집기 코드는 v14 소스에 원본 그대로 포함한다.

운영 D1의 `workbench`, `facility_notes`, `audit`는 조회 시점에 모두 0행이었다. 따라서 소스 저장소에 있는 개발용 preview DB의 4개 작업본·6개 감사 이력을 운영 현재 상태로 취급하지 않는다. 편집기에는 제보 1개, 사진 메타 1개, 이미 대체된 구조물 초안 1개, 보완 요청 작업 2개가 있었다. 적용된 공개 레이어는 0행이었다.

`service-domain.json`, `editor-domain.json`에는 테이블 구조와 업무 행을 담았다. 모든 업무 테이블은 한 페이지 25개 이하에서 끝났고 다음 페이지가 없었으며, 잘리거나 생략된 값도 없었다. 세부 수는 `export-manifest.json`에서 확인한다.

인증 계정·세션·에이전트 연결 코드는 읽거나 옮기지 않는다. 업무 행의 계정 식별자·개인 연락처도 공개에서 제외한다. 감사 기록 14행 중 로그인·연결 코드 발급·계정 연결에 해당하는 6행은 인증 기록으로 분리했다. 나머지 8행은 업무 이력으로 보존한다. SQL의 필수 식별자 칸에는 로그인할 수 없는 로컬 재현용 표지만 넣는다.

## 로컬 재현

서비스와 편집기의 각 `drizzle/*.sql`을 순서대로 적용한 **새 로컬 DB**에 `service-domain.sql`, `editor-domain.sql`을 적용한다. 두 seed는 원본 DB를 수정하는 도구가 아니며 기존 DB의 내용을 지우지 않는다. 운영 DB나 원본 개발 DB에 실행하지 않는다. Python sqlite3 메모리 DB에서 기존 마이그레이션 적용과 seed 입력, 테이블별 행수 일치까지 확인했다.

로컬 대상은 서비스 `data-private/experience/preview.sqlite`, 편집기 `toolkit/data-private/editor.sqlite`이다. 공개 미리보기와 원본 파일은 `uploads/`에 원래 R2 키(`report-preview/`, `report/`, `proposal/`)로 보존한다. 저장소 루트에서 `node tools/import-served-domain.mjs`를 실행하면 편집기 `data-private/uploads/` 아래에 같은 상대 경로로 복사한다. 같은 SQL을 다시 적용할 때는 기존 DB를 보존하며, 로컬 파일의 내용이 다르면 덮어쓰지 않고 중단한다. 로컬 승인자 계정은 편집기 실행 시 새로 생성한다.

COMMONS의 일시 공유방 5행은 조회 시점 참조 기록으로만 보존하며 seed에는 넣지 않는다. 접속자 행은 0개였고 운영 토큰이나 접속 상태를 복원하지 않는다.

## R2 포함 범위

공개 모자이크 미리보기 1개(1,426바이트)와 제보 원사진 1개(JPEG, 502,723바이트·1152×2048), `superseded` 상태의 구조물 초안 1개(PNG, 740,085바이트·465×1024)를 포함한다. 원본 두 개는 사용자가 로그인한 기존 승인자 세션에서 이미지 GET 응답을 그대로 내려받았다. 스크린샷이나 재인코딩 이미지로 바꾸지 않았으며 크기·형식·치수와 SHA256을 검증했다. 원래 객체 키·조회 경로·검증 시각·해시는 `export-manifest.json`, 각 파일 해시는 `files-sha256.json`에 기록한다. 현재 D1 사진·초안 기록에 대응하는 원본 이미지의 누락은 없다.

원사진은 승인자 열람용이고 이전 초안은 이미 대체된 이력이다. 내보낸 제보의 `review` 상태와 초안의 `superseded` 상태는 바꾸지 않는다. 새 로컬 DB에서는 이 상태로 복원하며, 같은 SQL을 이미 적용한 로컬 DB에서는 이후의 작업 상태를 보존한다. 새 로컬 승인자 세션에서 원래 인증 API로 열람하며, 이전 초안의 공개 이미지 API는 계속 404를 반환하는 것이 정상이다. 서비스에 포함된 승인 파사드 사진은 별도의 자료다.

외부 VWorld 원본 타일 캐시는 이 D1/R2 내보내기의 범위가 아니다. 서비스와 같은 외부 참조 경로를 사용한다.
