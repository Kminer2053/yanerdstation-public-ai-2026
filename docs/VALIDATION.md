## 임시 실행과 읽기 확인

사용자가 4196·4197 포트의 제출본 임시 실행을 허용했다. 두 서버는 `127.0.0.1`에만 연결하고 기존 프로세스를 변경하지 않았다. 다음 읽기 응답이 정상임을 확인했다.

- 서비스 `/api/catalog`: 337 기준 시설·경로 스냅샷.
- 서비스 `/api/demo/sales?date=2026-07-18`: 독립 합성 자료임을 `basis`에 명시한 매출 JSON.
- Toolkit `/api/public/stations`: 공개 역 목록.

화면 클릭·외부 지도 렌더링과 구동영상은 별도 증거로 관리한다. 이 API 응답 검사는 외부 VWorld의 성공을 대신하지 않는다.

## 공개본 최종 파일 검사

node_modules·dist·data-private·Git 이력을 제외한 공개 소스에서 원본 영상/3D 타일 바이너리(`mp4`, `webm`, `mov`, `b3dm`, `pnts`, `bin`), 운영 hosting 파일, 사용자 로컬 절대경로와 개인 이메일을 발견하지 않았다. 일반적인 고신뢰 API키·토큰·private key 서명 검사도 검출 0건이다.

사진 대체 대상은 96개이며 원사진 없이 절차 생성한 표지로 모두 덮어썼다. 매출·이용인원은 원값을 입력으로 쓰지 않는 생성기로 다시 작성했다. 개인정보 신청서와 서명 문서는 공개 소스에 포함하지 않는다. 이 검사는 알려진 패턴과 구성 범위를 확인한 것으로 모든 권리와 개인정보 검토를 보증하는 인증은 아니다.

## 남는 한계

실제 유료 모델 호출·운영 정확도·응답 비용은 이번 검사에서 측정하지 않았다. 테스트의 모델 응답은 모의값이다. Ebi 자동 호출 연결도 별도다. 원사진·실제 영업자료·원본 VWorld 자산은 배포하지 않아 공개 clone은 합성 표지와 샘플 수치로 표시한다. 외부 공간 서비스와 재이용·시연 조건은 별도 확인해야 한다.

루트 지도 번들은 minify 후 약 545kB로 Vite의 500kB 안내가 있었다. 빌드는 성공했으며 번들 크기 개선은 잔여 품질 과제다.
