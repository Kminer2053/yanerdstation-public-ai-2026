# 공개 범위와 제출 스냅샷

기준 소스: `ea4a5f9` (2026-10-15), 기존 정밀 서비스와 Toolkit. 이후 11월의 COMMONS 경량 모델·멀티접속은 이번 제출에서 제외했다. 운영 저장소의 Git 이력은 복제하지 않는다.

## 공개용 변경

- 운영 hosting 파일과 Supabase 과거 seed, 내부 개발 문서, 기존 홍보영상, 원사진, 개인 연락처와 사용자 로컬 경로를 제외·일반화했다.
- 매출·이용인원은 원값과 관계없는 정수 산식으로 만들었다. 사진 96개는 코드로 만든 합성 표지로 교체하고 스냅샷 이미지 해시도 다시 계산했다.
- 기본 서비스 실행을 Vite 4196으로 맞춰 로컬 D1 API adapter를 포함했다. 원본 비공개 타일 캐시는 자동 선택하지 않는다.
- `.env.example`은 비어 있는 선택 설정이다. AI API는 서버 환경을 명시한 경우에만 연결한다.
- 화면에도 합성 샘플과 실제 운영/실시간 자료가 다름을 표시했다.
- root·Toolkit의 별도 설치와 별도 빌드가 필요하다. 운영 배포와 운영 DB를 포함하지 않는다.

정밀 코드의 기능은 보존하지만 데이터가 교체되므로 공개본의 매출·이용인원 결과와 원 서비스의 그림을 동일한 결과로 해석하면 안 된다. 외부 지도 서비스 장애와 권리 조건은 별도다.

## 제외 유형

| 유형 | 제외 이유 |
|---|---|
| `.openai/`, `toolkit/.openai/` | 기존 계정·호스팅 연결 분리 |
| `.env*` 실제 설정·키 | 비밀값과 운영 연결 분리 |
| `data-private/`·SQLite·업로드 | 사용자·승인자·제보 원본 비공개 |
| `supabase/` 과거 스키마·대용량 seed | 과거 운영/원본 카탈로그 전체 재배포 제외; 새 D1 스키마는 유지 |
| 내부 `docs/`, Toolkit 내부 문서 | 다른 작업·과거 대회·사용자 맥락 분리 |
| `public/media/` 및 영상 | 과거 홍보·타대회 영상 제외 |
| 원사진·KTX 사진 | 재배포권·개인정보 검토 범위 분리; 합성표지로 대체 |
| 원본 3D Tiles·캐시 | 외부 공간 데이터 재배포 금지 |
| COMMONS·presence | 작업 중인 별도 경량·멀티접속 범위 제외 |
| 신청서·서명·연락처 | 공개 소스 저장소에 개인정보 문서 미포함 |

기준 archive에서 제거한 개별 경로는 `EXCLUDED_FILES.json`이다. 사진 대체 목록은 `tools/public-synthetic-images.json`이다. 외부 권리는 `NOTICE.md`를 따른다.
