# COMMONS 현재화 표시 정합성 수정

이전 v76은 신규 시설의 데이터와 사진을 포함했지만, 실제 정면 표시와 기존 파사드 보정 결과까지 검증하지 못했다. 테라로사의 상하 반전, 일부 프레임의 잘못된 면 배치, 시설 이동 후 대상이 화면 밖에 놓이는 문제를 수정했다. 원본 서울역 설정·사진·승인 기록은 변경하지 않는다.

## 수정 내용

- Cesium 1.142의 `CoplanarPolygonGeometry`는 일부 면에서 위치 정점 순서와 ST 순서를 독립적으로 처리한다. 승인 자료의 UV는 이 결과를 보정한 값이므로, Three.js의 입력 모서리에 그대로 붙이면 보정이 다시 뒤집힌다. 실제 엔진의 출력 위치를 원본 모서리와 대응시킨 검증 캐시를 사용한다.
- 일반 coplanar 31개 파사드·96패치를 전수 확인했다. 15개 파사드·32패치의 대응을 정규화하고, 테라로사 정면의 방향을 복원한다. 정상적인 측면은 유지한다. 전역 `flipY`나 사진 파일 회전은 사용하지 않는다.
- 일반 승인면은 원본 앱과 같이 법선 앞쪽으로 0.065m 이동한다. 원래 벽과 같은 위치에 두고 GPU polygon offset에만 의존하던 차이를 제거한다.
- `F02WL072-FRAME-S01`은 일반 사각형 대체 경로로 처리하지 않는다. 원본 프레임 모듈의 정확한 6면 모서리·자동 UV·삼각형과 전용 0.015m offset을 사용한다.
- S11 두 매장의 기본 사진은 원래 셰이더가 최종 표출하는 아래쪽 709/724 범위를 사용한다. 원본 PNG나 승인 자료를 변경하지 않고 파생 이미지 2개를 다시 생성한다.
- 시설 앞 이동 후 대상 방향으로 시선을 맞춘다. 안내센터·TRAIN MATES처럼 큰 신규 시설은 등록 크기에 맞춰 카메라 거리를 조정한다. 이동은 기존 유효 보행 지점과 서버 승인 절차를 그대로 사용한다.
- 카메라의 충돌 검사가 파사드만 확인하던 한계를 수정한다. 원본 건축·천장·신규 시설의 실제 불투명 삼각형을 공간 격자로 조회해 목표 위치와 보간 중 위치 모두를 보정한다. 테라로사 부근에서 카메라가 `3F:columns` 안으로 들어가 화면 전체가 회색이 되던 경로를 재현하고 차단했다. 아바타의 보행 데이터는 바꾸지 않으며, 매우 좁은 곳에서는 기존 근접 카메라 정책에 따라 자기 아바타를 숨긴다.

## 실제 포함 여부 대조

신규 시설은 원본 앱 생성자 6종을 실행해 사진 17면·박스 146개와 비교하고, 실제 Three.js 모듈이 만드는 18개 메시의 재질·사진·픽킹·층별 가시성·자원 해제를 확인한다. 각 사진의 실제 모서리 → Cesium 출력 ST → 원본 셰이더와 crop → PNG 픽셀을 합성해 COMMONS와 대조한다. TRAIN MATES 동측은 엔진의 정점 반전과 `flipV`가 상쇄되므로 그대로 유지한다.

건축 원본을 다시 추출해 이전 자산과 비교한 결과, 1,372개의 숨김 삼각형·400개의 제거 삼각형과 최종 바이너리·atlas가 동일하다. 현재 자료에서 기존 철거·숨김 정책이 누락된 증거는 없다. 2026-11-02 공개 Toolkit API의 추가 `assets`와 `overlays`는 모두 비어 있었으며, 제보 초안을 임의로 추가하지 않는다.

## 검증과 재생성

일반 빌드는 저장소의 검증 캐시를 사용하며 Cesium을 내려받거나 브라우저 런타임에 추가하지 않는다. 검증되지 않은 새 coplanar 면은 추정 변환하지 않고 빌드를 중단한다.

```sh
node tools/build-commons.mjs
node tools/build-commons-architecture.mjs
node tools/build-commons-custom.mjs
npm run test:commons
npm run test:replacement-surfaces
```

공식 앱과 같은 Cesium 1.142 번들을 별도로 확보하면 실제 엔진 전수 검증을 실행할 수 있다. 번들 버전과 SHA-256을 확인하며, 엔진 파일은 저장소나 배포물에 넣지 않는다.

```sh
node tools/test-commons-coplanar-uv.mjs /absolute/path/Cesium-1.142.js --verify-hall
COMMONS_CESIUM_ENGINE=/absolute/path/Cesium-1.142.js node tools/test-commons-custom.mjs
```

59개 승인 파사드·61개 시설·3,762개 보행점·10개 층간 연결과 기존 좌표계는 유지한다. 기존 정밀 서비스와 공개편집기 설정을 덮어쓰지 않는다. 시설이 데이터 목록에 포함된 사실과 실제 화면에서 보이는 사실은 별도로 검증한다.
