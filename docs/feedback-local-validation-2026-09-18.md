# 야!너두 스테이션 — 로컬 검증 인계

## 실행본과 공개 상태

- 소개·서울역: http://127.0.0.1:4196/?scene=local
- 서울역 방문안내: http://127.0.0.1:4196/seoul/?role=visitor&scene=local
- 대전역 독립 편집기: http://127.0.0.1:4197/?scene=local
- 공개 편집기 코드: https://github.com/Kminer2053/ya-nerd-station (별도 공개 저장소)
- 현재 로컬 서비스는 저장된 지도 타일을 사용한다. 브이월드 연결 재시도는 진행하지 않았다. 외부 라이브러리·폰트까지 완전히 오프라인인 패키지는 아니다.
- 서울역 Sites 공개본 v49는 이번 변경으로 배포하지 않았다. 편집기 Sites 프로젝트는 등록만 했으며 아직 미배포다.

## 반영한 내용

1. `야!너두 스테이션` 소개 페이지와 서울역 검증 프로토타입을 분리하고, 별도 편집기로 연결했다.
2. 방문안내는 출발 위치 선택, 시설 정면 보기, 빠른 따라걷기·보행효과·가상 보행자 기본 표시, 자유탐색, 층/시설 순간이동, 카메라 수동 비교를 제공한다. 경로는 깊이 관계를 적용하며 가상 보행자는 경로 주변의 연결된 보행점으로 분산한다.
3. 상권분석은 데스크톱 구역 조망, 상대 스케일 지도 지표, 매장 카드, 객단가·마진·비용 가정 계산을 제공한다.
4. 운영관리는 데스크톱 총괄 지도/데이터/주의사항, 확정 등록 시설·경로·층간연결·유동 데이터 조회, 별도 시연 수정본 저장으로 재구성했다. 시연용 비밀번호 `station2026`은 화면에도 공개되며 보안 수단이 아니다.
5. 서울역 확정 원본은 revision 334 기준 읽기 전용으로 고정했다. 승인된 파사드 94건(이미지 80개, 약 45.5MB)을 로컬 스냅샷으로 고정하고 실시간 Supabase 구독과 분리했다. 기존 Supabase 원격 데이터 자체를 삭제하거나 RLS 정책을 변경하지 않았다.
6. 대전역 편집기는 별도 저장소, 로컬 SQLite/업로드, 배포 시 별도 D1/R2를 사용한다. 서버 검증으로 서울역을 편집 대상으로 허용하지 않는다. 구조물, 면별 파사드, 점/영역, N:N 연결, 순서형 경로, 일별/시간별 유동 자료를 관리한다.

## 남아 있는 검증·제약

- 다른 역의 정확한 제공 목록은 아직 검증되지 않았다. `그 외 제공 역 · 목록 검증 및 준비 중`으로 표시하며 40개를 임의로 생성하거나 일괄 다운로드하지 않았다.
- 카메라는 사용자 허용 후 수동 비교하는 기능이다. 실제 장치 권한 승인·촬영 테스트, AR 위치 정합은 하지 않았다.
- 실내/야외 전환은 검토 가능한 좌표·높이 범위에 따른 근사 분류다. 실제 조명 시뮬레이션·정밀 실내 측위가 아니다.
- 유동인구는 원자료/추정 기준을 바탕으로 만든 모델이며 실측 동시 체류 인원이 아니다. 성능 제한 시 표시 인원과 추정 인원을 구분한다.
- 대전역 참고 격자는 장애물 자동 판정이나 최단 경로 생성 기능이 아니다. 기존 메시 자체를 변형하는 대신 숨김 후 대체 구조물을 추가한다.
- 운영관리에서 확정 출도착 영역 및 층간접속점 좌표의 원본 변경은 잠겨 있다. 시연 수정본에서 시설 보행점·경로 순서·통행 방향·시간별 데이터 등을 수정할 수 있다.
- 공개 배포 전에는 브이월드 이용 조건/연결, 실기기 카메라·현장 동선, 서버 권한·사용량 제한을 추가 확인해야 한다. 유료 저장공간 증설은 하지 않았다.
