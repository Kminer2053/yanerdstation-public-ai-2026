# 시설 정면 보기 가림 전수조사 (2026-09-26)

## 방법

`tools/audit-facade-views.mjs`가 로컬 서울역 장면(scene=local)에서 서비스와 같은 `catalog-focus` 경로로 시설 115곳의 정면 보기를 하나씩 띄우고 깊이 버퍼로 가림을 잰다.

- 정면 사진이 있는 시설(55곳, `cameraHeading` 보유): 사진 면 전체(바닥 위, 11×6점)가 화면 안에 있고 앞을 가리는 표면이 없으면 보임. 카메라 1.5m 안으로 파고드는 구조물(10×7 화면 격자)은 별도 감점.
- 정면 사진이 없는 시설(60곳, 에스컬레이터·엘리베이터·매표기 등): 기준점이 물체 내부에 찍혀 있어, 처음 맞은 표면이 목표까지 거리의 마지막 28% 안이면(시설 자신·주변) 보임.
- 약한 시점(사진 면: 가시 85% 미만 또는 근접 2% 초과 / 그 외: 가시 60% 미만 또는 근접 5% 초과)은 각도·줌 깊이·높이각 후보를 변경 폭이 작은 순으로 시험하고, 보행 가능 격자 위에 서는 카메라를 우선한다.
  - 사진 면: 정면 ±40°, 거리 0.45~1.4배, 높이각 -3/-12/-22°
  - 그 외: 8방향, 기본·18·12·8m, 높이각 -22/-35/-50°
- 보정 후보는 전후 캡처를 사람이 확인해 채택·제외한다.

### 검수 후 제외

공항철도 출입구 에스컬레이터, 1층 에스컬레이터(서울지하철 연결) 2·4, 7·8번홈 에스컬레이터(1층→2층), 5·6번홈 에스컬레이터(2층행), 2층 에스컬레이터(1번출구 앞, 하행).
수치상 개선이지만 보정본이 기둥·바닥판·발판 근접 화면이어서, 에스컬레이터와 주변이 함께 보이는 원래 시점을 유지한다. 제외 사유는 보정 파일의 `rejected`에 남아 재실행해도 다시 적용되지 않는다.

## 참고 사항

- 정면 사진이 없는 시설(`FAC-INPU_*`)의 기준점 높이는 층별 일괄값(바닥+1.58m)이고, 다수가 에스컬레이터 개구부나 엘리베이터 박스 안에 찍혀 있다. 원래 시점이 어색한 곳은 좌표 자체를 정비하는 편이 근본 해결이다.
- 선상 매장 부스(F02WL072 계열)는 기본 거리 공식(4.5~9m)이 부스 사이 간격보다 길어 카메라가 옆 부스 벽 안으로 들어가는 경우가 있었다.
- 가는 난간·기둥(10cm 안팎)은 표본 간격보다 좁아 가림으로 잡히지 않을 수 있다.

## 다시 실행

```bash
npm run dev:collab -- --port 4175   # 다른 창에서 개발 서버
node tools/audit-facade-views.mjs --out outputs/facade-audit          # 조사만 (전후 캡처·results.json)
node tools/audit-facade-views.mjs --apply-from outputs/facade-audit/results.json   # 검수 후 보정 파일 반영
npm run test:facade-views
```

조사 중에는 개발 서버가 새로 고치지 않도록 `app/`·`src/` 파일을 수정하지 않는다.
