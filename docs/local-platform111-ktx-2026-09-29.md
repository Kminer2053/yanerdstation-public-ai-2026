# 플랫폼111 KTX 광고 이미지 교체

로컬 4202에 적용. GitHub 커밋·운영 Sites 배포는 이번 작업에서 수행하지 않음.

## 변경

- 도시 시안 대신 실제 KTX #38 사진 사용. Minseong Kim / Wikimedia Commons, CC BY-SA 4.0.
- 2,167 × 941 WebP, 538,168바이트. 원본 비율 유지 축소만 적용, 크롭·합성 없음.
- 사진과 문구의 종횡비를 각각 적용해 높이 전체를 채우며 상하 흰 띠가 생기지 않음.
- 긴 광고 면에는 정방향 반복. 사진의 KTX 로고가 좌우 반전되지 않도록 기존 거울 반복 제거.
- 기존 4초 이미지/문구 교대, 공유 타이머 및 전용 이미지 sampler 유지. 영상 디코딩·프레임별 이미지 업로드 추가 없음.
- 열차안내 사진, 시설 형상, 확정 자료, 서울역 저장 잠금 유지.
- 사진 출처는 지도 Data attribution 및 서비스 자료·추정 기준에서 제공. 공개 자산 폴더에 출처·변경·라이선스 기록 포함.

## 검증

- 2프레임 자동 검사: 공유 타이머·숨김/모션 감소·정리, 사진 픽셀 비율, 로고/문구 정방향, 파일·라이선스 포함 확인.
- 조명·플랫폼111 회귀 검사, experience 검사 및 프로덕션 빌드 성공.
- 실제 내장 브라우저에서 KTX 사진 프레임과 문구 프레임 확인. 열차안내 영역 보존, 콘솔 오류 없음.
- 새 이미지 로컬 HTTP 200. 이미지 교체 이후 FPS는 별도 재측정하지 않음.
- 화면 증거: 상위 작업폴더 `outputs/platform111_ktx_20260929/KTX-적용화면.png`.
